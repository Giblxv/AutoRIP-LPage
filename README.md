# AutoRIP-LPage

Landing page comercial do AutoRIP para operações DTF e DTF UV.

A página usa apenas capturas reais da interface do AutoRIP e da interface mobile usada no APK, sem imagens geradas ou mockups fotográficos. As imagens ficam em `public/images`.

## Desenvolvimento

```bash
npm run build
npm run dev
```

A saída estática é gerada em `dist/`. Os CTAs comerciais abrem o WhatsApp `11 95333-6229`.
